This is a ReadMe File 

This repository is designated for updating the Equity Issuance Stock Data from Xiaoji LIN 

The original paper is from "External Equity Financing Shocks, Financial Flows, and Asset Prices" by Frederico, Xiaoji, and Fan (RFS, 2019) 

The Data folder contains the original data downloaded directly from Xiaoji LIN's website 
Webpage is accessed via "https://sites.google.com/a/umn.edu/xiaojilin/data"
